# SovAI Knowledge Base

Knowledge base and reference files for **SovAI — Sovereign On-Premise Agentic AI Workbench**.

This repository stores documents and other files that can be processed and used by SovAI for local knowledge retrieval, document Q&A, and RAG.

## Purpose

The files in this repository will be used as source knowledge for SovAI's local AI pipeline.

SovAI can later process these files using:

- Document parsing
- OCR
- Embeddings
- RAG
- Local model inference

## Files

Files can be added directly to this repository for now.

The repository structure will be organized and expanded later as the knowledge base grows.
